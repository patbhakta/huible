Implements W5 of the accepted Persona Vault v1.8 build plan (HU-2309 §1.7.2, mapping M-0R-E), including the CA C2 clinical boundary.

## What landed

1. **`src/huible/persona/tools.py` (new)** — deterministic, local, era-gated tool lanes:
   - **In-world era clock** — `in_world_now()`: the persona's "today" pins to
     `era_knowledge_boundary` once the real date passes it (time-of-day carries
     through; a clock time is not a historical fact). In-era real dates pass
     through. Missing/unparseable boundary is fail-closed (no date claims at all).
   - **Caretaker routing** — `is_temporal_question()`: conservative
     message-shape classifier (same measured-discriminator doctrine as the W3
     competence wall) for date/time-class questions;
     `caretaker_reply()`: clearly-labeled out-of-persona answer from the real
     clock, never in-voice, never piercing the era wall.
   - **Hobby/interest tool** — `is_interest_question()` shape classifier drives
     the interest lane in the ContextBuilder.

2. **ContextBuilder wiring** (`src/huible/persona/context.py`):
   - Era-gated in-world clock line in the system prompt (structural machinery,
     same category as the era-boundary line — not a voice sheet). `real_now=None`
     keeps the exact pre-W5 prompt shape (deterministic test callers unaffected).
   - Interest lane: on interest-shaped turns, one message-conditioned vector
     probe; preference/fact atoms pass the *same* hard gates as the prompt
     firewall (confidence fail-closed, disclosure scope, era boundary) + the
     activation floor, capped at 4 lines, rendered as the YOUR INTERESTS
     section. This is the vault-derived interest/topic map (W1 retrieval feeds
     it) — hobbies are talked from the persona's own corpus lines, never
     base-model invention. Never counted as activated memories (evidence
     separation like the W3 deflection exemplars).

3. **Caretaker channel in the chat path** (`src/huible/api/app.py`):
   - New branch placed **after** the G1 crisis pre-check, the G6 consent gate,
     and the G8 risk-flag enforcement (incl. all short-circuits), **before**
     retrieval/generation. On a caretaker-class turn: no retrieval, no
     generation, no working-memory capture, no `_record_turn` — the persona
     corpus and conversation history are never fed (§1.6b).
   - `trace.caretaker` (`CaretakerView`) records kind, the era boundary not
     pierced, and `gates_cleared=["g1_crisis","g6_consent","g8_risk"]` as CA C2
     audit evidence. `risk_enforcement` stays on the trace (G8 evaluated).
   - `trace.interest_tool` (`InterestToolView`) records the interest-lane fire.
   - Injectable `now_fn` → `application.state.chat_now` (hermetic tests).
   - Metrics: new outcome label `caretaker` (per-turn counter + latency).

4. **Settings** (`era_clock_enabled`, `caretaker_channel_enabled`,
   `interest_tool_enabled`) — all default **on**: deterministic, local, no
   network/spend (unlike the W4 lane, which defaults off because it calls a
   network service).
